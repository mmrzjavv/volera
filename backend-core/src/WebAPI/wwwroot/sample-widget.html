Sample page – Chat widget & AI widget

This page embeds both the company chat widget (talk to support) and the AI widget (chatbot). Chat: bottom-left. AI: bottom-right.

1. Chat widget (support chat)

Script: widget.js with data-widget-id="w_uLnrr4wtPydNRBzh", data-color="88207a", data-position="bottom-left".

Widget ID is used directly so "Start chat" works without resolving by branch. You can also use data-branch="<branch-guid>" instead of data-widget-id to resolve the widget by branch.

2. AI widget (chatbot)

Script: ai-widget.js with data-widget-id="w_uLnrr4wtPydNRBzh" (same as chat widget so both use the same branch), data-color="0d9488", data-position="bottom-right". Requires SignalR (loaded below).

You can use data-widget-id (as here) so the AI widget uses the same branch as the chat widget, or data-branch="<branch-guid>". The branch must have AI widget set up and content indexed in Admin → AI Widget.

Chat widget abilities

  • 💬 Text messages – Send and receive messages in real time.
  • 📎 File attach – Use the paperclip to upload images, PDFs, or documents; the link is sent in the next message.
  • ↩️ Reply – Click "Reply" on any support message to quote it; reply preview appears above the input with a clear button.
  • 👍 Reactions – Support agents can add emoji reactions to messages; they appear under the message and update live.

Real-time updates (new messages, reaction changes) are delivered over SignalR while the chat is open.

How to open this page

Ensure the .NET backend is running (e.g. dotnet run in the WebAPI project). Then open this page from any origin:

  • Via backend: http://localhost:5002/sample-widget.html
  • Or via Live Server / static server (e.g. port 5500) – the widgets load from the backend URL above.

If the backend runs on another host/port, set window.WIDGET_BACKEND_URL before the widget scripts (see source).
